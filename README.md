# bbi Photo Size Reducer

Shrink photos to a target file size (KB) and dimensions (px), right in your browser.
**Your photos never leave your device.** No upload, no sign-up, no install.

👉 **Try it:** https://bbi222.github.io/bbi-photo-shrink/

## Features
- Target size: under 100 KB / 200 KB / 500 KB / 1 MB / custom
- Resize by width, or fit to an exact size (e.g. 3.5×4.5 cm ID photo, 413×531)
- Batch processing, save one by one or all as ZIP
- Paste (Ctrl+V) or drag & drop
- Explains why when the target can't be reached
- English / Korean (auto-detected, switch with KR | EN)

Output is saved as JPG. HEIC is not supported in some browsers.

# bbi 사진 용량 줄이기

브라우저에서 바로 사진의 목표 용량(KB)과 크기(px)를 맞춰 줄여요.
**사진은 내 기기 밖으로 나가지 않아요.** 업로드, 가입, 설치가 필요 없어요.

👉 **바로 쓰기:** https://bbi222.github.io/bbi-photo-shrink/

## 기능
- 목표 용량: 100KB / 200KB / 500KB / 1MB 이하, 직접 입력
- 가로 기준 줄이기, 정확한 크기 맞추기 (증명사진 3.5×4.5cm = 413×531)
- 여러 장 한 번에, 하나씩 또는 ZIP으로 저장
- Ctrl+V 붙여넣기, 끌어다 놓기
- 목표 용량을 못 맞추면 이유를 알려줘요
- 한국어 / English (자동 선택, KR | EN 버튼)

결과는 JPG로 저장돼요. 일부 브라우저에서는 HEIC를 열 수 없어요.
